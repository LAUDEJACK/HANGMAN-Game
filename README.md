# Hangman Game 🎯

A classic Hangman game developed in **Python**, focused on code best practices, modularity, and data validation.

## Features
- Command-line interface (CLI) with ASCII art.
- Strict user input validation (blocks numbers, multiple characters, and extra spaces).
- Life preservation logic (prevents losing lives on repeated guesses).
- Play-again support for multiple continuous sessions without restarting the app.

## Built With
- **Python 3.10+**
- Built-in modules (`random`, `typing`)

## How to Run the Project

```bash
# Clone the repository
git clone https://github.com/LAUDEJACK/hangman-python.git

# Enter the directory & run
cd hangman-python
python main.py
```
